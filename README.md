# 📊 Python Data Analysis & Visualization

Welcome to my Python Data Science learning repository! This project tracks my complete step-by-step roadmap from mastering fundamental array operations to scraping web datasets and building professional-grade data visualizations.

---

## 🛠️ Tech Stack & Core Libraries
* **Language:** Python 3.x
* **Data Processing:** NumPy & Pandas
* **Data Retrieval:** Web Scraping (BeautifulSoup / Requests)
* **Visualization:** Matplotlib (Modern Object-Oriented Style) & Seaborn

---

## 📂 Repository Structure & Key Projects

| File / Folder | Topic Covered | Core Description |
| :--- | :--- | :--- |
| `data_visualization.ipynb` | **Modern Matplotlib** | 2x2 grid subplots, nested loops mapping, stack plots, histograms, and customizable layout alignments. |
| `numpy_operations.ipynb` | **NumPy Arrays** | 3D array manipulation, array indexing, conditional transformations, and vector math. |
| `pandas.ipynb` | **Pandas Framework** | Data exploration using DataFrame indexing, dataset parsing, and automated `.to_csv()` exports. |
| `webScraping.ipynb` / `webScrapinActivity.ipynb` | **Web Scraping** | Live web scraping structures, structural HTML data mining, and parsing static target web links. |
| `globalAirQuality.csv` / `raw_data.csv` | **Datasets & Cleansing** | Working data pools tracking exploratory functions (`.head()`, `.tail()`, `.sample()`) and handling missing values. |

---

## 📈 Featured Visualizations Covered
1. **2x2 Subplot Grids:** Programmatic subplot plotting over nested iterations mapping automated dataset scales.
2. **Dynamic Stack Plots:** Visualizing complex structural marketing funnels and tracking organic vs. direct metrics.
3. **Data Distributions:** Custom-binned frequency histograms managing strict range definitions and outlier boundaries.
